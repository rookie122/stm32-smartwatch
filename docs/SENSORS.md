# 传感器与算法

STM32 固件位于 `upstream/OV-Watch-main/Software/OV_Watch`。

| 模块 | 实现 | 指标边界 |
| --- | --- | --- |
| EM7028 心率 | 任务延时 50 ms，7 点峰值比较，使用相邻峰间隔换算 bpm | 约 20 Hz 为名义采样频率，未记录参考仪器对照误差 |
| MPU6050 计步 | 启用 DMP pedometer，读取累计步数 | 未记录人工计数对照准确率 |
| MPU6050 抬腕 | 根据加速度计算 roll/pitch，配合 RTC 唤醒判断 | 姿态阈值不代表角度测量精度 |
| LSM303 罗盘 | 加速度姿态补偿磁场后计算方位角 | 未记录磁校准及参考角度误差 |
| SPL06 气压与海拔 | 读取器件校准系数，完成温压补偿，再按 101325 Pa 基准换算海拔 | 气压随天气变化，固定基准不能保证绝对海拔精度 |
| AHT21 温湿度 | I2C 读数及原始数据换算 | 器件标称典型精度 ±0.3℃、±2%RH；并非整机实测精度 |

AHT21 指标参考[官方产品手册 V1.3](https://www.aosong.com/userfiles/files/media/AHT21%E4%BA%A7%E5%93%81%E6%89%8B%E5%86%8C%20A3%2020210123.pdf)。手册注明 25℃、3.3V 出厂测试条件，适用于非冷凝条件，不含迟滞和非线性；数值不是全量程最大误差。

## 固件中的已知问题

- `Hr_Ave_Filter` 累加变量未初始化，并且没有返回语句。
- 心率环形队列的物理数组索引未按时间顺序重排；峰值时间使用 16 位变量，存在时间截断风险。
- 心率任务仅接受 `50 < bpm < 120` 的结果。
- AHT21 初始化及忙状态判断需要修正逻辑/位运算和运算符优先级；无符号温度换算还需处理负温度。
- 环境页将读数转换为整数，显示步长不等于传感器精度。
- 血氧页面未实现有效采集算法。

电脑端健康模块输入为合成数据。提醒去抖、恢复滞回和冷却参数描述状态机行为，不代表生理测量精度。硬件测量精度需要以参考设备对照记录验证。
